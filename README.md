## 🎮 How to Play

- A number appears in the **"Hit"** box.
- Click the **bubble** that matches the number.
- For each correct click:
  - ✅ Your **score** increases by 10.
  - ✅ New bubbles are generated.
- The game runs on a **60-second timer**.
- At the end, the game displays "Game is Over..!".

---

## 🧠 Features

- Dynamic bubble generation.
- Real-time score tracking.
- Timer countdown with game end state.
- Fully responsive layout.
- Clean and simple UI.
